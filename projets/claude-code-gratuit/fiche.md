# Claude Code gratuit sur ton PC : ça marche vraiment ?

> Fiche du 15/11/2026, à ta demande (remplir les créneaux radar de janvier). Placée au **jeu. 7 janv. 2027, 18 h**, **provisoire, à confirmer au radar**. Vidéo **calculée**. Idée 30 de [`strategie.md`](../../strategie.md), non notée (relevé YouTube du 15/11). Titre provisoire. Ta décision du 15/11 : le sujet reste en janvier, il n'avance pas.

**Inspiration** (vues relevées sur YouTube le 15/11) : Sharbel A., [*Unlimited Claude Code For Free (Runs On Your Computer)*](https://www.youtube.com/watch?v=K8lVHiFnN2A) (1,18 M de vues en 3 semaines, publiée le 18/10) ; Kevin Stratvert, [*How to Use Claude Code for FREE with Ollama*](https://www.youtube.com/watch?v=NkkAwdm2k7s) (115 K en 5 jours). En français : Cedric Oden IA, [*Claude Code gratuit et illimité*](https://www.youtube.com/watch?v=iakl2AAZqWM) (65 K en 5 jours) et Krysalid (8,7 K en 9 jours). **Le sujet est déjà traité en français** : en janvier, il faut un angle qu'ils n'ont pas.
- **Leur angle (à ne pas reprendre)** : le tuto « une commande (`ollama launch claude`), et c'est gratuit et illimité ».
- **Notre angle** : **le test honnête** : avec une carte de 8, 12 ou 16 Go, quel modèle tient, ce que Claude Code fait bien en local, et où ça casse (contexte trop court, outils, vitesse). On s'appuie sur ce que tu as appris avec Strata et Pi (`strata connect`, l'API Anthropic sur localhost).

## Pistes (à sourcer)

- Ce qui est vraiment gratuit (le harnais) et ce qui ne l'est pas (le modèle, la machine).
- Le contexte : Claude Code envoie beaucoup d'instructions (comparer avec Pi, chiffres de la vidéo Strata).
- Ollama, LM Studio ou Strata comme moteur ; le meilleur modèle de code par palier de VRAM.
- Le renvoi à [Strata](../strata-test/fiche.md) (16 nov.) et à [Quel modèle ta carte peut faire tourner ?](../modele-par-vram/fiche.md) (18 janv.).

## Points à vérifier

1. La commande et la doc d'Ollama, le jour du script (ça change vite).
2. Les conditions d'utilisation de Claude Code avec un autre modèle.
3. Décider : calculé ou filmé chez toi (comme Strata) ?
4. `sources.md` à créer.
