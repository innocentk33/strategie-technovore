### Ce que ça dit pour nous

- **Demande** : le mot « sqlite » seul fait ~13 K recherches/mois dans le monde, avec une concurrence moyenne ; « sqlite database » a une concurrence basse (27/100). La recherche « comment fonctionne sqlite » est sous le seuil : la vidéo vivra des **suggestions**, pas de la recherche.
- **Angle libre en français** : une seule vidéo FR (live de 43 min, 8 K vues). Notre angle (l'histoire d'un logiciel qui est partout) n'existe pas.
- **Titre** : ne pas reprendre « 300 KB » (le chiffre est faux, fait 5) ni « beat Oracle » sans le reformuler. Mots à mettre : « SQLite », « base de données », « téléphone ».
- **Ce que ByteMonk a déjà pris** : le destroyer, le 1 000 milliards, le « testé comme un avion ». Notre valeur ajoutée : les corrections, l'explication en motion design de « pas de serveur », et le lien avec le téléphone du spectateur.
- **Grosse vidéo hôte récente** : « I Ran 4 Databases on the Same $12 Server » (Arjay McCandless, 176,9 K, octobre 2026) montre l'intérêt actuel pour les bases de données ; la chaîne a aussi une série à >600 K vues.

## Pour le script : ce qu'on peut dire, ce qu'on ne dit pas

**Formulations sûres**
1. « Il y a plus de 4 milliards de smartphones, et chacun contient des centaines de fichiers SQLite : sqlite.org estime qu'il y a probablement plus de mille milliards de bases SQLite en service » (#1, #32).
2. « SQLite est probablement utilisé plus que tous les autres moteurs de bases de données réunis » (#2).
3. « Il est dans chaque Android, chaque iPhone, chaque Mac, chaque Windows 10 et 11, et dans Chrome, Firefox et Safari » (#4).
4. « Toute la bibliothèque pèse moins d'un mégaoctet : 600 à 750 Ko selon la machine » (#5).
5. « En 2023, pour 156 000 lignes de code, il y avait 92 millions de lignes de tests : 590 fois plus » (#6).
6. « Tout est parti d'un destroyer de l'US Navy : Richard Hipp écrit un logiciel pour le chantier Bath Iron Works, le serveur de base de données tombe, et un collègue lui dit : pourquoi tu n'en écris pas une toi-même ? » (#14, d'après Hipp).
7. « D'après sqlite.org, Airbus confirme que SQLite tourne dans le logiciel de vol de l'A350 » (#11).
8. « Hipp raconte avoir passé un an, à 60 heures par semaine, à tester chaque branche du code ; après ça, il n'a plus reçu de rapports de bugs d'Android » (#27).
9. « Le code est dans le domaine public, et les développeurs promettent de le maintenir jusqu'en 2050 » (#16, #19).
10. « Le mode WAL écrit les changements dans un fichier à côté, puis les reverse dans la base : les lecteurs ne bloquent plus l'écrivain » (#25).

**À ne pas dire, ou à dire autrement**
- « 300 Ko » : faux aujourd'hui, dire « moins d'un mégaoctet » (#5, #34).
- « SQLite a battu Oracle » : faux en popularité (Oracle 1er, SQLite 11e chez DB-Engines) ; dire « plus installé que tous les autres réunis » (#30).
- « Certifié DO-178B » ou « certifié pour les avions » : dire « testé avec une méthode pensée pour les normes de l'aviation » (#10).
- « Deux ingénieurs » : dire « une petite équipe à plein temps » (#29).
- Les 5 millions d'installations de MySQL et le million de PostgreSQL (#28).
- « General Dynamics » et « Symbian » : absents des sources lues (#14, #27).
- « Le composant logiciel le plus déployé de tous » : dire « le 2e, après libz » (#3).
- « Ces revenus financent SQLite » (#17).
- WhatsApp sans « d'après des analyses forensiques » (#22).
