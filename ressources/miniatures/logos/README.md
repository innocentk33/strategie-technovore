# Logos pour les miniatures

Demande de l’auteur confirmée le 16/11/2026 : employer les véritables logos pour que le sujet soit reconnu immédiatement. Conserver proportions et couleurs ; adapter les tuiles autour du logo à notre charte. Une illustration reconnaissable de l’emblème est possible, notamment la baleine DeepSeek. Ne pas remplacer une marque par un faux monogramme ou une icône générique.

Les fichiers sont des copies exactes des sources indiquées. Le logo Qwen est un PNG officiel ; les autres sont des SVG. Utiliser leur `viewBox` natif et `preserveAspectRatio="xMidYMid meet"`. Les anciens SVG monochromes et `logos.js` restent disponibles pour les maquettes existantes ; les nouvelles icônes ne partagent pas toutes leur `viewBox` de 24 × 24.

À vérifier sur chaque rendu : logo identifiable à 168 px, contraste suffisant, espace net entre le titre et les tuiles, y compris la copie décalée du texte. Dans une vidéo sur Claude Code avec un moteur local, associer l’emblème au terminal Claude Code, pas à la puce locale.
