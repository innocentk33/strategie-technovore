# Ressources partagées

Ce qui sert à plusieurs vidéos. Range-le ici plutôt que dans un projet : tu le retrouveras à la vidéo suivante.

| Dossier | Contenu | Utilisé par |
|---|---|---|
| `remotion/` | Bibliothèque d'animations réutilisables : carte, hexagones, serveurs, flux de données | Uber (créée en S3), Waze, WhatsApp |
| `miniatures/` | Modèles de miniature, polices, palette | Toutes les vidéos |
| `audio/` | Musiques, bruitages, jingles (note la licence de chaque fichier) | Toutes les vidéos |
| `voix/` | Réglages de la voix clonée, mots difficiles à prononcer | Toutes les vidéos |

Crée chaque dossier quand tu y mets le premier fichier.
Les vidéos d'inspiration (celles qui dépassent la moyenne de leur chaîne) sont dans [`strategie.md`](../strategie.md), section 1.
